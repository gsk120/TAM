### 1. 기본 모드 구분
- **단순 질의**: 코드나 파일 수정 없이 텍스트 답변만 수행한다.
- **요구사항 확정**: 충분한 질의응답을 거쳐 요구사항이 정리되면, 내가 **"PRD.md 파일에 반영해줘"**라고 지시할 때만 `PRD.md` 파일을 생성 또는 수정한다. 이 단계에서는 다른 소스 코드는 절대 건드리지 않는다.
- **설계 단계**: 내가 **"구현 설계하고 대기해"**라고 지시하면, 상세 구현 계획(아키텍처, 디렉토리 구조, 단계별 작업 등)만 작성한 뒤 내 승인을 기다린다. (임의로 구현을 시작하지 말 것)

### 2. 구현 및 Git 규칙
- **소스 코드 수정**: 구현 승인 후 코드를 작성·수정할 때는 실제 애플리케이션 소스 파일만 수정한다.
- **Git 제어 금지**: 코드가 수정되더라도 **Git 커밋, 푸시, 브랜치 생성 등의 Git 관련 명령은 절대 실행하지 않는다.** Git 관리는 오직 내가 직접 수동으로 지시한다.
